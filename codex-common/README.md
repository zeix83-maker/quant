# 공통 Codex 지침

공통 규칙의 단일 원본은 `COMMON.md`이며 현재 버전은 `CODEX COMMON OPTIMIZATION v1`입니다.
프로젝트 루트 AGENTS.md에는 고유 규칙과 원본 로딩 지시만 둡니다.

## 설치
이 저장소를 로컬에 체크아웃한 상태에서:
```sh
python codex-common/install.py
```
Windows에서 python 대신 py 명령을 사용하는 환경은 `py codex-common/install.py`로 실행합니다.
기본 대상은 CODEX_HOME 또는 사용자 홈의 .codex입니다.
다른 환경에 설치할 때는 `--codex-home <경로>`를 사용합니다.

설치기는 기존 개인 지침을 보존하며 표시된 공통 블록만 추가·교체합니다.
변경 전 백업을 남기고 같은 내용은 재기록하지 않습니다.
비어 있지 않은 AGENTS.override.md 또는 잘못된 블록 마커가 있으면 변경 없이 중단합니다.
기존 지침이 블록 밖에서 같은 내용을 반복하는 경우 자동 삭제하지 않습니다.
오래된 블록을 의도적으로 다시 설치하면 해당 버전으로 교체되므로 체크아웃 버전을 확인합니다.

## 설치하지 않은 환경
프로젝트 AGENTS.md의 명시적 로딩 지시에 따라 원본을 읽습니다.
이미 같은 버전이 현재 세션에 로딩되었으면 다시 읽지 않습니다.
원격 원본은 커밋 SHA로 고정하고, 접근 실패 시 누락을 보고합니다.
링크 자체는 자동 상속이나 설치를 의미하지 않습니다.
클라우드·컨테이너·다른 PC는 각각 독립 환경이며 Windows 설치를 뜻하지 않습니다.

## 변경과 검증
공통 의미가 바뀌면 버전 표시와 설치기의 BEGIN/END, 두 저장소의 참조를 함께 갱신합니다.
새 원본 커밋을 먼저 만든 뒤 소비 저장소가 그 커밋을 참조하도록 합니다.
원격 갱신 스크립트를 내려받아 곧바로 실행하는 방식은 사용하지 않습니다.
설치 후 새 Codex 세션에서 적용 지침의 경로와 버전을 확인합니다.
quant와 Trustboard 각각에서 공통 규칙 1회 및 프로젝트 규칙 로딩을 확인합니다.
실행 환경의 실제 Codex 로딩 검증 전에는 전 환경 적용 완료로 보고하지 않습니다.

복원할 때는 최신 AGENTS.md.backup-* 내용을 확인한 후 AGENTS.md로 되돌립니다.
